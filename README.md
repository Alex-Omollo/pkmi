# PKMI Website

A public-facing website for Phenomenal Kingdom Mothers International, built with Next.js App Router, React, TypeScript and custom CSS.

## Routes

- `/` — Home
- `/about` — About PKMI
- `/our-work` — Programs and initiatives
- `/events-news` — Events, news and gallery entry point
- `/membership` — Membership information and enquiries
- `/contact` — Contact and general enquiries

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Notes

- This is the initial frontend scaffold. Content is based on the five PKMI overview slides supplied for the project.
- The membership page is informational; member accounts and payment processing are intentionally out of scope for this first phase.
- Replace the temporary hero imagery and emblem crop with approved, high-resolution PKMI brand assets and real activity photographs before launch.
